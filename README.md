# BINUS Freshman Leader — Thank You

Halaman statis responsif untuk menyampaikan terima kasih kepada Freshman Leader BINUS, dirancang dengan gaya Liquid Glass: transparansi, blur, highlight, dan warna aurora.

## Jalankan lokal

Buka `index.html` langsung di browser, atau gunakan extension Live Server di VS Code.

## Deploy ke GitHub Pages

1. Buat repository GitHub baru, lalu push seluruh isi folder ini ke branch `main`.
2. Buka repository → **Settings** → **Pages**.
3. Pada **Build and deployment**, pilih **GitHub Actions**.
4. Push berikutnya ke `main` otomatis menjalankan workflow dan menerbitkan situs.

URL situs akan tampil di ringkasan workflow setelah deploy selesai.
